The "Brutal Recruiter" in your Pocket
Career Assistant Pro is a high-performance iOS application designed to bridge the gap between talented candidates and the modern ATS (Applicant Tracking System). Most resumes fail because they are generic; this app audits them with the "brutal honesty" of a Top 1% Technical Recruiter.

🧠 The Intelligence Layer
The app features a unique Dual-Engine Architecture to ensure zero downtime and maximum intelligence:

Primary Engine: Groq (Llama 3) for near-instant, high-speed inference.

Secondary Engine: Google Gemini 3 Flash for deep-context resume audits and complex career strategy.

Smart Fallback: Automatic provider switching logic ensures the user never sees a "Server Down" message.

✨ Key Features
Elite Resume Audit: Real-time analysis of keywords, STAR-method metrics, and AI-buzzword detection.

Job Tailoring: Instantly aligns your experience to a specific Job Description while maintaining your authentic voice.

Punchy Writing Suite: Generates modern cover letters (no "I am writing to..." boilerplate) and high-conversion recruiter cold emails.

PDF Extraction: Seamlessly parses existing resumes using Apple's PDFKit.

🛠 Technical Stack
Language: Swift / UIKit

Architecture: Modular Service-Oriented Design (Separation of UI, Prompts, and Networking)

Security: - Keychain Integration: Securely stores user-provided API keys.

Configuration Secrets: Uses .xcconfig patterns to keep developer credentials off version control.

UI/UX: Custom animations using CAEmitterLayer and CALayer for a premium, high-tech feel.

🛡️ Security & Privacy
This app supports Bring Your Own Key (BYOK). Users can toggle between the developer's free tier or use their own Groq/Gemini keys for higher rate limits. All resume data is processed in memory and never stored on external servers.
